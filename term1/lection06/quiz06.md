# Контрольный тест (quiz) №6

**Охват:** материалы [лекции 5](../lection05/lection05.md) и [семинара 5](../seminar05/seminar05.md)

**Формат:** вопросы с выбором одного верного варианта (где не указано иное).

---

### Вопросы

**1.** (Задача по оператору `%`, пары **5** и **6**) Какое равенство **верно** для остатка от деления во встроенном языке 1С?

- А) `5 % 6 = 0`
- Б) `5 % 6 = 5`
- В) `6 % 5 = 1`
- Г) `6 % 5 = 5`

**2.** (Пример) Что произойдёт при вычислении выражения **`1 + "два"`** (первый операнд — число, строку к числу привести нельзя)?

- А) строка автоматически станет нулём, результат `1`
- Б) число преобразуется в строку и выполняется конкатенация, результат `"1два"`
- В) платформа выдаст исключение
- Г) результатом будет `Неопределено` без исключения

**3.** (Пример) Пусть `Д = '2024.01.12 12:00:00'`. Чему равен результат выражения **`Д + 60`** (как на лекции: число — секунды)?

- А) `'2024.01.13 12:00:00'`
- Б) `'2024.02.12 12:00:00'`
- В) `'2024.01.12 12:01:00'`
- Г) `'2025.01.12 12:00:00'`

**4.** С какого индекса нумеруются элементы массива во встроенном языке 1С (в типичной модели, разобранной на лекции)?

- А) с единицы
- Б) с нуля
- В) с минус один для служебных элементов
- Г) индексация задаётся в свойствах конфигурации

**5.** Почему циклические ссылки в массиве или структуре нежелательны?

- А) платформа запрещает их на уровне компиляции
- Б) сборщик мусора может не освободить память до конца сеанса
- В) они недопустимы в тонком клиенте
- Г) из них нельзя сделать `JSON`

**6.** Чем **список значений** принципиально отличается от **соответствия** в контексте лекции?

- А) список значений может хранить только числа
- Б) у элементов списка значений есть **представление** (в т.ч. для пользователя)
- В) соответствие всегда отсортировано по ключу
- Г) соответствие нельзя передавать между клиентом и сервером

**7.** Какой принцип проектирования документов рекомендуется?

- А) один документ должен отражать одну хозяйственную операцию (максимум две тесно связанные)
- Б) все операции заказа лучше объединить в одном «мегадокументе» со статусами
- В) документы в учебной конфигурации не должны проводиться
- Г) каждый документ обязан иметь не менее пяти табличных частей

**8.** Какие операции в языке запросов 1С в «привычном» виде **недоступны** по сравнению с классическим SQL?

- А) только `SELECT`
- Б) `INSERT`, `UPDATE`, `DELETE`
- В) любые соединения таблиц
- Г) временные таблицы

**9.** Как во встроенном языке запросов обычно создают временную таблицу для последующего использования в том же пакете?

- А) `CREATE TEMP TABLE`
- Б) конструкция с `ПОМЕСТИТЬ В`
- В) `Новый ВременнаяТаблица`
- Г) только через объектную модель `МенеджерВременныхТаблиц` без запроса

**10.** Что такое **виртуальная таблица** «Остатки» регистра накопления с точки зрения разработчика?

- А) физическая таблица, которую нужно создать вручную в СУБД
- Б) упрощённый доступ к остаткам; под капотом платформы — сложный запрос
- В) таблица, которая существует только в файловой базе
- Г) отчёт СКД без источника данных

**11.** Что возвращает метод **`НайтиПоКоду`** справочника, если элемент с таким кодом **не найден**?

- А) пустую ссылку справочника
- Б) `NULL`
- В) `Неопределено`
- Г) исключение без возможности перехвата
