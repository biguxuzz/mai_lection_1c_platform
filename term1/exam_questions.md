# Вопросы для экзамена по курсу term1

**Курс:** «Разработка на платформе 1С:Предприятие»  
**Факультет информационных технологий, 2 курс**

**Формат билета:** теоретическая часть (развёрнутый ответ, **5–10 минут**) + практическая часть (**~10 минут**, **другая тема**).  
**Рекомендуемый объём билета:** 1–2 вопроса (≈25–40 минут на билет).

**Охват:** лекции 1–10, семинары 2–10, курсовой проект. См. [1CPlatform.md](1CPlatform.md).

**База для практики:** учебная конфигурация курса (справочники «Склады», «Номенклатура», «Контрагенты»; документы прихода/расхода; регистры «ТоварыНаСкладе», «Взаиморасчёты» и др.) или эквивалентная конфигурация, предоставленная на экзамене.

| Параметр | Значение |

### Критерии оценивания

**Теоретическая часть**

- **3:** названа суть, перечислены ключевые понятия, есть пример.
- **4:** структурированный ответ, связь между понятиями, ограничения или типичные ошибки.
- **5:** полный ответ, сравнение альтернатив, обоснование выбора.

**Практическая часть**

- **3:** решение в целом верное, есть существенные пробелы или ошибки синтаксиса/логики.
- **4:** рабочее решение с незначительными недочётами (именование, контекст клиент/сервер).
- **5:** корректное решение, учтены граничные случаи, код/запрос читаемы и соответствуют практике курса.

**Итоговая оценка за билет** — среднее арифметическое оценок за теоретическую и практическую части, округление до целого по математическим правилам.

*Пример:* теория — 4, практика — 5 → итог **5**; теория — 3, практика — 4 → итог **4**; теория — 3, практика — 3 → итог **3**.
