# Контрольный тест (quiz) №7

**Охват:** материалы [лекции 6](../lection06/lection06.md) и [семинара 6](../seminar06/seminar06.md)

**Формат:** вопросы с выбором одного верного варианта.

---

### Вопросы

**1.** Чем файл обновления `.cfu` обычно выгодно отличается от полной поставки для базы заказчика с большим объёмом данных?

- А) CFU всегда содержит пользовательские данные
- Б) CFU меньше по размеру; накат обновления часто быстрее полной перезаливки
- В) CFU можно применить только без режима поддержки
- Г) CFU заменяет собой файл `.dt`

**2.** Что означает формулировка «конфигурация на замке» после загрузки из поставки?

- А) конфигуратор нельзя открыть без ключа /unlockconfiguration 
- Б) редактирование ограничено политикой поддержки
- В) база доступна только для чтения в режиме 1С:Предприятие
- Г) файл поставки зашифрован паролем поставщика

**3.** Зачем при создании разностной поставки указывать предыдущую версию конфигурации?

- А) чтобы платформа автоматически удалила все расширения
- Б) чтобы построить дифф и получить CFU
- В) чтобы сбросить номер версии к 1.0.0
- Г) это требуется только для файловых баз

**4.** При параллельных изменениях одних и тех же объектов у поставщика и у заказчика в первую очередь может потребоваться:

- А) удаление платформы 1С у заказчика
- Б) сопоставление объектов
- В) отказ от обновлений навсегда
- Г) переход только на хранилище без Git

**5.** Чем хранилище конфигурации 1С принципиально отличается от Git в части ветвления?

- А) в хранилище нельзя откатиться назад
- Б) линейная история, ветвления нет
- В) Git нельзя использовать в 1С
- Г) хранилище хранит только картинки

**6.** Почему время захвата корня конфигурации в хранилище нужно минимизировать?

- А) корень можно захватить только на ночь
- Б) корень может удерживать только один разработчик
- В) корень не существует в метаданных
- Г) захват корня отключает отладку у остальных разработчиков

**7.** Сколько контуров рекомендуется для промышленной разработки?

- А) два: Git и EDT
- Б) четыре: разработка, тестирование, предпрод, прод
- В) три: клиент, сервер, веб
- Г) один: продуктив

**8.** Нужна ли отдельная лицензия на запуск хранилища ?

- А) да, всегда нужна клиентская лицензия на каждого разработчика отдельно для файла хранилища
- Б) нет: хранилище не эксплуатируют как ИБ с пользовательскими данными
- В) нужна только для PostgreSQL
- Г) хранилище работает только в облаке 1С:Фреш

**9.** Почему конфигурация, подключённая к хранилищу 1С, мешает нормальной работе с EDT?

- А) EDT не устанавливается на Windows
- Б) механизмы хранилища конфликтуют с EDT
- В) механизмы хранилища всегда удаляют Git
- Г) EDT работает только с пустой базой

**10.** Чем оборотный регистр накопления может отличаться от остаточного в части кода движений?

- А) оборотный всегда требует вид приход/расход так же, как остаточный
- Б) у оборотного регистра нет вида движения
- В) оборотный регистр не используется в документах
- Г) остаточный регистр не имеет измерений

**11.** Чем формат проекта EDT принципиально отличается от работы Cursor с выгрузкой конфигурации в файлы?

- А) это один и тот же каталог без отличий
- Б) у EDT свой формат проекта; требуется конвертация в формат конфигуратора
- В) Cursor не работает с 1С, он используется только для построения pipeline сборки
- Г) EDT хранит только расширения
